Encryption Keys

🔑 Key Ceremony (one-time setup, production) Generate a shared 256-bit medical field key:
openssl rand -base64 32

Add to each node's node.conf → custom.odat_medical_field_key.
The MatchingAuthority is the only node that decrypts. Hospital nodes only encrypt at registration.
